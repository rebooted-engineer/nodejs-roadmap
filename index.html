// about this roadmap

Not a tutorial.
A curriculum.

Most Node.js tutorials teach you to print "Hello World". This roadmap teaches you to build systems. Every phase hands you a real-world problem and gives you the tools to solve it.

AI is built into the workflow from day one — not as a gimmick, but as a real engineering tool you'd actually use on the job.

01

Project-First Learning

Topics are introduced only when a project needs them. Context makes concepts stick.

02

AI-Augmented Projects

Build AI chatbots, LLM-powered APIs, and semantic search — using OpenAI, Anthropic, and vector databases.

03

Production-Grade Habits

Testing, logging, Docker, CI/CD — not an afterthought. Baked into every project.

04

Portfolio-Ready Output

Every project is a deployable, explainable system you'd be proud to show an interviewer.

// the curriculum

The roadmap.

6 phases. Build small → build real → ship to production.

Phase 01

Node.js Foundations

Weeks 1–3 · 3 Projects
Beginner
Project 01

CLI Task Manager

A terminal-based task manager that reads/writes to a JSON file. Your first real interaction with Node's runtime, modules, and file system.

Topics Covered
Node.js runtime CommonJS vs ESM process.argv fs module readline JSON I/O NPM basics package.json
Project 02

File-to-Markdown Converter

Convert CSVs and plain text files into formatted Markdown. Learn async file handling, Streams, and Node's event loop properly.

Topics Covered
Streams & piping Event loop Callbacks Promises / async-await Error handling Buffer path module
Project 03

Simple HTTP Server

Build a raw HTTP server without Express. Serve static files, parse URLs, handle routing — all from scratch to understand what frameworks do for you.

Topics Covered
http module Request / Response objects URL parsing MIME types Static file serving Status codes
Phase 02

Express.js & REST APIs

Weeks 4–6 · 3 Projects
Beginner
Project 04

Recipe REST API

A full CRUD REST API for managing recipes. Learn Express deeply — routing, middleware chains, input validation, and error handling patterns.

Topics Covered
Express setup Routing & params Middleware chains express.json() CRUD operations Zod validation Error middleware HTTP status semantics
Project 05

URL Shortener Service

A production-style URL shortener with redirect tracking, rate limiting, and basic analytics — stored in a database.

Topics Covered
SQLite / better-sqlite3 express-rate-limit Redirects (301/302) Unique IDs (nanoid) Query params Environment variables dotenv
Project 06

AI-Powered Smart Search API

Add a /search endpoint that uses OpenAI embeddings to find semantically similar recipes — rather than exact keyword matches.

AI Integration — OpenAI Embeddings
Topics Covered
OpenAI SDK Embeddings Vector similarity In-memory vector store API key management Axios / node-fetch
Phase 03

Databases, Auth & Real-World Patterns

Weeks 7–10 · 3 Projects
Intermediate
Project 07

Job Board Backend

Full-featured REST API for a job listing platform with Postgres, Prisma ORM, relations, filtering, and search. Think cut-down LinkedIn Jobs.

Topics Covered
PostgreSQL Prisma ORM Migrations Relations (1:N, M:N) Connection pooling Filtering & pagination EXPLAIN ANALYZE
Project 08

Authentication System

Implement JWT-based auth + refresh token rotation + Google OAuth. The kind of auth system you'd actually run in production.

Topics Covered
Hashing (bcrypt) JWT (access + refresh) Passport.js Google OAuth2 Session vs. token auth Middleware auth guards Role-based access OWASP basics
Project 09

AI Resume Screener

Connect the Job Board to Claude's API. Upload a CV — get a structured match score, strengths, and gaps against a job description. Automate it all.

AI Integration — Claude API + Structured Outputs
Topics Covered
Anthropic SDK Multipart file upload Multer PDF parsing Structured outputs Async workers Webhook callbacks
Phase 04

Real-Time, Caching & Queues

Weeks 11–14 · 3 Projects
Intermediate
Project 10

Real-Time Chat App

A multi-room chat application with usernames, history, and presence indicators — driven by WebSockets. The system supports thousands of concurrent users.

Topics Covered
Socket.io WebSocket protocol Rooms & namespaces Redis Pub/Sub Presence tracking Event-driven arch Scaling sockets
Project 11

Async Email + PDF Pipeline

Accept a form submission, queue a job with BullMQ, generate a PDF receipt and send a personalised email — without blocking the API response.

Topics Covered
BullMQ + Redis Workers & queues Job retry/backoff Nodemailer PDF generation Dead-letter queues Concurrency control
Project 12

AI Chatbot with Conversation Memory

A streaming LLM chatbot that remembers past conversations, with semantic memory via pgvector, and graceful fallbacks when context is too long.

AI Integration — LLM Streaming + pgvector RAG
Topics Covered
LLM streaming (SSE) pgvector RAG pattern Redis caching Token counting Cache-aside pattern Rate limiting
Phase 05

Production, Testing & DevOps

Weeks 15–18 · 2 Projects
Advanced
Project 13

Fully Tested API with CI/CD

Add a comprehensive test suite (unit + integration + E2E) to the Job Board API, wire up GitHub Actions, deploy to Railway with zero-downtime deploys.

Topics Covered
Jest & Supertest Test doubles (mock/stub) Testcontainers GitHub Actions Docker & Compose Zero-downtime deploy Health checks OpenAPI / Swagger
Project 14

Observability Platform

Instrument the chatbot with structured logging, distributed tracing, and Prometheus metrics. Identify and fix a real performance bottleneck using these tools.

Topics Covered
Pino (structured logs) OpenTelemetry Jaeger tracing Prometheus metrics Grafana dashboards p99 latency Memory profiling
Phase 06

Capstone — Advanced AI Systems

Weeks 19–24 · 2 Projects
Advanced
Project 15

AI Agent + Tool-Use System

Build an autonomous AI agent that can search the web, read documents, query your database, and execute code — using Claude's tool use API. Think a lite version of Cursor.

AI Integration — Agentic Loops + Tool Use
Topics Covered
Agent loop pattern Tool/function calling Anthropic tool use Sandbox execution Memory management Tool result parsing Guardrails Rate + cost control
Project 16

Micro-SaaS — Knowledge Base Platform

A full knowledge base product: document ingestion, semantic search via pgvector, multi-tenant auth, Stripe billing, usage limits, and a polished API — deployed on GCP Cloud Run.

AI Integration — Full RAG + Semantic Search
Topics Covered
Multi-tenancy Stripe integration Webhooks (Stripe) GCP Cloud Run Chunking strategies Document ingestion RBAC Rate-limit per plan Load testing
